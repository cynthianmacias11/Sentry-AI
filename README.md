# Sentry-AI
AI-Assisted Email Triage &amp; Purge
Sentry is an AI-assisted email security automation project designed to identify, evaluate, and purge malicious or unwanted emails while maintaining an auditable record of its decisions.
Sentry began as an experiment in combining Python automation, cybersecurity concepts, and AI-assisted decision making. The project grew from a simple question: Could an AI-assisted system help automate repetitive email security tasks while still maintaining human-readable reasoning and safeguards?
## SAFETY CONSIDERATIONS
API credentials are stored outside the source code
Email and Password credentials are stored outside the source code
Destructive actions have safeguards
Actions are logged
Testing should use a controlled mailbox
False positives are a consideration
AI decisions aren't blindly trusted
Reinforce Human-In-The-Loop
